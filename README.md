# CoinSwap — конвертер валют

Конвертер валют на чистом HTML, CSS и JavaScript. Курсы берутся из открытого API, сборка не нужна.

**Демо:** https://m1sterklesh.github.io/coinswap/

## Стек

- HTML5: `main`, `section`, `form`
- CSS3: переменные в `:root`, Grid, Flexbox, тёмная тема, адаптив (< 480px)
- Vanilla JS (ES6+), без библиотек, `async/await`, `fetch`
- API: [open.er-api.com](https://open.er-api.com/v6/latest/USD), ключ не нужен

## Что реализовано

- Конвертация по кнопке или Enter, без лишних запросов на каждое изменение суммы
- Списки валют строятся из ответа API, по алфавиту, у 15 популярных валют есть русские названия
- Кнопка ⇄ меняет валюты местами и сразу пересчитывает
- Результат крупно, под ним курс за единицу
- При смене базовой валюты курсы запрашиваются заново (на 10 минут кешируются в памяти)
- Ошибки показываются под формой, без `alert()`: пустая сумма или сумма ≤ 0, не число, одинаковые валюты, сбой сети
- Пока идёт запрос — спиннер, текст «Загрузка курсов...», кнопки заблокированы
- Последняя пара и сумма сохраняются в `localStorage`, по умолчанию 100 USD → EUR
- Фон слегка подсвечивается под состояние: успех или ошибка
- Доступность: `label` у полей, `aria-live` для результата и ошибок, поддержка `prefers-reduced-motion`

## Структура

```
├── index.html
├── css/style.css
└── js/
    ├── api.js    — fetchRates(base): запрос и проверка ответа
    ├── ui.js     — fillSelects, renderResult, showError, showLoading, setBackground
    └── main.js   — обработчики, валидация, кеш курсов, localStorage
```

Скрипты подключены обычными тегами `<script>` в порядке `api.js → ui.js → main.js`, поэтому всё работает при открытии файла двойным кликом.

## Запуск

Откройте `index.html` в браузере.

Курсы носят справочный характер и не являются предложением купить или продать валюту. Учебный проект для портфолио.

Курсы: [ExchangeRate-API](https://www.exchangerate-api.com). Шрифт: Inter (Google Fonts).
